# 온결클린

> 가상 업체 포트폴리오 · 실제 예약 및 결제 불가

아이보리, 짙은 청록색, 연한 민트를 사용한 반응형 청소업체 홈페이지입니다. 외부 패키지, 백엔드, API 키 없이 동작하는 HTML/CSS/JavaScript 정적 사이트입니다.

## 기능

- 입주·이사·거주청소와 포함·제외 범위 소개
- 지역·유형·주거 형태·공급면적·욕실·베란다·선택 서비스 기반 예상 견적
- 평 또는 ㎡ 입력, 최소 기본비와 1,000원 올림 적용
- 기타 지역, 단독·복층주택, 계산 면적 5~60평 이외는 숫자 견적 숨김
- 접착제·특수 오염과 가전 2대 이상은 추가 비용 미포함으로 명시
- 서울 시간 기준 지난 희망일 차단, 예약 가능 여부는 표시하지 않음
- 견적 문장 복사 및 클립보드 사용 불가 시 수동 복사 창
- 개인정보를 받지 않는 상담 시연 모달
- 싱크대 수전·인덕션·창틀·욕실·베란다·수납장 6곳의 클로즈업 전후 사진 12장과 확대 비교 슬라이더
- 자주 묻는 질문, 모바일 고정 버튼, 키보드 탐색과 모션 감소 설정 지원

## 로컬 실행

Node.js 20 이상이 설치된 환경에서 프로젝트 폴더를 열고 실행합니다. 의존성 설치는 필요 없습니다.

```sh
npm start
```

브라우저에서 `http://127.0.0.1:4173`을 엽니다. ES 모듈을 사용하므로 파일을 직접 더블클릭하는 대신 HTTP 서버로 실행해주세요.

## 검증

```sh
npm test
```

예시 A(312,000원), B(523,000원), C(200,000원), 최소 청소비, 면적 환산·올림, 개수 검증, 상담 대상, 추가비 미포함, 서울 시간 날짜 제한, 복사 문구를 검증하는 19개 테스트가 포함되어 있습니다.

## GitHub Pages 공개

저장소 기본 브랜치는 `main`입니다. GitHub 저장소의 **Settings → Pages → Build and deployment**에서 **Deploy from a branch**, **main**, **/(root)**를 선택하면 됩니다. `.nojekyll`이 포함되어 있어 별도 빌드가 필요 없습니다. 모든 웹 자산 경로는 상대 경로로 작성하여 프로젝트 하위 경로에서도 동작합니다.

공개에 필요한 파일은 `index.html`, `style.css`, `app.js`, `estimate.js`, `assets/`, `.nojekyll`입니다.

## 이미지 및 포트폴리오 원칙

`assets/hero.webp`와 `assets/closeup-*-before.webp`, `assets/closeup-*-after.webp` 12장은 이 프로젝트를 위해 OpenAI 내장 이미지 생성 도구로 만든 AI 시연 이미지입니다. 실제 현장, 실제 고객, 실제 작업 실적을 나타내지 않습니다. 생성 프롬프트는 [ASSETS.md](./ASSETS.md)에 기록했습니다. 파일은 WebP로 최적화했습니다.

실존 업체 전화번호·주소·사업자등록번호, 가짜 고객 후기, 실제 예약·결제·연락처 수집 기능을 포함하지 않습니다. 입력 조건은 브라우저 메모리에서만 사용하며 서버나 외부 분석 서비스로 전송하지 않습니다.

## 구조

```text
index.html          화면과 콘텐츠
style.css           반응형 스타일
app.js              입력·결과·복사·모달·슬라이더 동작
estimate.js         계산 및 견적 텍스트 생성
assets/             생성 이미지와 SVG 파비콘
tests/              견적 규칙 테스트
server.mjs          로컬 미리보기 서버
```
